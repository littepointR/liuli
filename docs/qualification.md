# 参考板验收记录 · 0.3.0-dev.1

2026-11-24 在 Windows 本机连接 Waveshare ESP32-S3-Touch-AMOLED-1.91，USB 303A:1001。ESP32-S3 rev 0.2，16 MiB Flash、8 MiB PSRAM、240 MHz、40 MHz QSPI。实板操作者已确认竖屏告警列表出画、点开和返回。双指按压时串口记录 FT3168 同时上报 2 个触点。基础、增强与基准镜像分别构建。当前版本处于开发阶段。

## 实板测量

同板同轨迹，每种连续场景采 32 帧，分位数使用 nearest rank。帧耗时从输入或消息提交到同步 QSPI 写完，包含模型更新、布局、像素和总线。QSPI 列包含设窗口与传输。复杂编辑路径覆盖组合提交、塑形、按字形 ID 栅格化、绘制 240 × 48 区域和删除。显示端实际亮起时间尚无光学测量。

RGB565 混合内核覆盖所有 16 档透明度、未对齐起点和尾部长度。65,536 像素同板耗时 18,595 µs（标量）和 2,399 µs（SIMD）。整帧确认弹层的 P50 比值为 2.15 倍。

字体位图由 esp_partition_read 按偏移读取，内存映射用于度量和索引。PSRAM 缓存预算为 4,096 B。上表使用 8 个 512 B 缓存页。对照运行的单窗口缓存每个滚动帧读取量 P50 为 262,144 B、帧耗时 P95 为 114.486 ms。相同轨迹改为分页后，预热的滚动帧读取量 P50 与 P95 均为零。表内跨条带数只计算同一字形在新条带首次出现的重复请求，实际 Flash 字节数来自后端计数器。复杂编辑使用随镜像嵌入的 OpenType 测试字体。修正增强任务栈后跑完全部 32 次编辑，整条轨迹最小剩余栈为 26,968 B。

两个配置首帧均发送 128,640 像素。启动时间以 esp_timer 起点计，电源接通至计时器启动的耗时未测量。UI 静态 RAM 为 Storage 加两块 240 × 8 的 u16 条带。模型、临时对象在任务栈中，板级驱动和 ESP-IDF 堆独立计量。Cortex-M4F 原参考固件的 ELF 静态 RAM 为 73,248 B，含两块 5,120 B 条带，.data 为 0 B。静态调用链审计结果为 4,776 B，门槛为 6,144 B。

轻睡已执行到 USB 链路中断。原始串口仅保留到最后一帧复杂编辑；再次进入 ROM 后读回的 RTC 数据未通过有效性检查。定时唤醒后成功重绘和延迟两项仍待验证。普通增强固件已恢复，其启动日志单独留档。
