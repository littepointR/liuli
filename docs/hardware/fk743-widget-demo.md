# FK743M2-IIT6 · Widget Demo 实板记录

2026-11-24 在同一块 STM32H743IIT6 排针版上验证，屏幕为 RGB050M1，800 × 480。四个固件取自 Windows 离线 SDK。每次覆盖并校验片内 Flash 后，通过 J-Link 自动向 Engine 输入按下和松开，依次进入各页面、返回首页。

| 后端 | UI 档位 | 固件字节 | 板端 CRC32 | 首帧提交耗时 | 整屏匹配 |
|---|---|---:|---|---:|---:|
| st-hal | basic | 170,108 | `79001366` | 120.17 ms | 17/17 |
| st-hal | enhanced | 923,432 | `df5f07a4` | 129.33 ms | 19/19 |
| embassy | basic | 171,628 | `71acf948` | 120.12 ms | 17/17 |
| embassy | enhanced | 923,524 | `f1783961` | 129.62 ms | 19/19 |

首帧提交耗时从引擎开始渲染首帧计到换帧并同步备用缓冲区。每行是一次实测。GT911 在四次回放中均通过 I²C 识别，各次记录到的 I²C 错误数均为 0。

每个检查点都检查应用的输入确认序号、页面、LTDC 使能位、图层使能位，以及当前扫描地址。将实板扫描缓冲区的无损快照解码为 768,000 字节，和同一输入对应的桌面 RGB565 参考帧逐字节比较。共通过 72 个检查点，覆盖 55,296,000 字节。将参考帧中坐标 (398, 103) 的一个像素翻转一位后，比较器在该坐标报告失败。

输入由 SWD 注入。这里测量的是控制器正在扫描的帧、显示提交耗时及 I²C 通信；面板光学响应和手指定位精度需要独立测量。最后留在板上的是 ST HAL + LL 增强档首页。

机器记录包含固件 SHA-256、每个检查点的输入坐标、序号、扫描地址和完整图像摘要。[逐帧实测数据](fk743-widget-demo.json) · [构建与回放命令](../fk743m2-iit6.md)

## Surface & depth 滚动复测

在同一块板和相同应用配置上，经 SWD 注入一次往返拖动，每步移动 24 像素，30 次移动均提交 321,360 个像素。下表使用 ST HAL + LL 增强档的两轮逐帧记录。耗时从进入呈现函数计到完成提交，包含等待垂直消隐。P95 使用最近秩。两组可见性由同一轨迹和桌面布局核对。[30 帧原始数据](fk743-depth-scroll.csv)

| 呈现场景 | 修复前 | 修复后 |
|---|---:|---:|
| 卡片接近完全可见，5 帧中位数 | 97.74 ms | 42.25 ms |
| 卡片完全隐藏，15 帧中位数 | 39.77 ms | 35.30 ms |
| 完整往返滚动，30 帧 P95 | 97.95 ms | 48.45 ms |

原固件的拖动采样重现了卡片可见时的耗时峰值。用同轮源码重新构建的基线还在进入页面时捕获到一次 LTDC FIFO 欠载。修复将可证明相同的背景扫描行合并计算，对不透明和透明的连续像素使用整段复制，并优先将热图层数据放在片内 SRAM。板级初始化将 LTDC 读优先级调到默认 CPU 与 DMA2D 优先级之上。[ST RM0433，AXI interconnect](https://www.st.com/resource/en/reference_manual/rm0433-stm32h742-stm32h743-753-and-stm32h750-value-line-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)

增强固件的独立扫描回读覆盖卡片滑出时半露、完全隐藏、滑回时半露和完全可见。ST HAL + LL（CRC32 `953e8945`）和 Embassy（CRC32 `402d91ea`）各通过四次 768,000 字节的整屏对照。两次回归均未记录到 LTDC FIFO 欠载或传输错误。此项测量覆盖显示控制器的扫描输入，面板光学响应未采样。

最后在 ST HAL + LL 固件上连续执行十轮往返，共 300 个移动帧。卡片接近可见时的中位数为 49.10 ms，隐藏时为 35.38 ms，全程 P95 为 51.92 ms，最慢帧为 59.13 ms。测试结束时 LTDC 粘滞状态为 `0x8`，FIFO 欠载和传输错误位均为零，应用已回到首页。

## Animations 播放验收

2026-11-25，ST HAL + LL 增强固件（CRC32 `0f4aef61`）通过十个演示页和首页的 21 个整屏检查点。工具从首页点开 Animations，选择 2.4 秒并播放。没有新的指针输入时，固件自主提交了 13 帧。暂停后观察 300 ms，帧计数保持不变。续播后又提交了 118 帧，完成后观察 250 ms，帧计数保持不变。终帧的 768,000 字节与桌面参考完全一致，LTDC 状态为 `0x8`。演示已返回首页。
