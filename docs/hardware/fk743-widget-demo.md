# FK743M2-IIT6 · Widget Demo 实板记录

2026-11-24 在同一块 STM32H743IIT6 排针版上验证，屏幕为 RGB050M1，800 × 480。四个固件取自 Windows 离线 SDK。每次覆盖并校验片内 Flash 后，通过 J-Link 自动向 Engine 输入按下和松开，依次进入各页面、返回首页。

| 后端 | UI 档位 | 固件字节 | 板端 CRC32 | 首帧提交耗时 | 整屏匹配 |
|---|---|---:|---|---:|---:|
| st-hal | basic | 170,108 | `79001366` | 120.17 ms | 17/17 |
| st-hal | enhanced | 923,432 | `df5f07a4` | 129.33 ms | 19/19 |
| embassy | basic | 171,628 | `71acf948` | 120.12 ms | 17/17 |
| embassy | enhanced | 923,524 | `f1783961` | 129.62 ms | 19/19 |

首帧提交耗时从引擎开始渲染首帧计到换帧并同步备用缓冲区。每行是一次实测。GT911 在四次回放中均通过 I²C 识别，各次记录到的 I²C 错误数均为 0。

每个检查点都检查应用的输入确认序号、页面、LTDC 使能位、图层使能位，以及当前扫描地址。将实板扫描缓冲区的无损快照解码为 768,000 字节，和同一输入对应的桌面 RGB565 参考帧逐字节比较。共通过 72 个检查点，覆盖 55,296,000 字节。将参考帧中坐标 (398, 103) 的一个像素翻转一位后，比较器在该坐标报告失败。

输入由 SWD 注入。这里测量的是控制器正在扫描的帧、显示提交耗时及 I²C 通信；面板光学响应和手指定位精度需要独立测量。最后留在板上的是 ST HAL + LL 增强档首页。
