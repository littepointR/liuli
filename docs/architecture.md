# `liuli` Architecture (`v0.2.0`)

`liuli` is a pure-Rust `#![no_std]`, zero-`alloc`, `#![forbid(unsafe_code)]` embedded GUI engine built on `embedded-graphics-core` (`0.4.1`) and `embedded-graphics` (`0.8.2`), paired with a pure-Rust host simulator, dual-font CJK bitmap packer, and Cortex-M4F ELF/stack audit firmware.

## Workspace Layout

- `crates/liuli-core`: Fixed-capacity retained tree (`MAX_NODES = 64`, `MAX_DEPTH = 12`, `MAX_TEXT_BYTES = 1024`, `MAX_SPARKLINES = 2`, `MAX_SPARKLINE_SAMPLES = 32`), scoped closure builder (`ViewBuilder` + `Children<'parent, 'pool>`), compact nodes (`RetainedNode = 224 B` host) and compact draw commands (`PaintCmd = 48 B`, `MAX_COMMANDS = 256`), bounded-stack layout engine, key-based reconciliation, damage tracking (`MAX_DAMAGE = 12`), unified input router, tab-aware focus/modal/page-restore trapping, `Easing::{Linear, EaseOutCubic}` animations (`MAX_ANIMATIONS = 8`), and long-press `RepeatState` timers (`400 ms` delay, `80 ms` repeat).
- `crates/liuli-text`: Dual-slot `FontSet` (`Body16` + `Small12`) LF4 v1 binary bitmap font parser, glyph iterator/line wrapper (`TextMeasurer` with CRLF, negative bearing, ellipsis, and `Start`/`Center`/`End` alignment), and RGB565 4-bit coverage (`a = 0..15`) channel blender.
- `crates/liuli-render`: Strip buffer (`BandTarget` implementing `OriginDimensions` + `DrawTarget<Color = Rgb565>`), scene rasterizer (supporting `ProgressBar`, `Sparkline`, and 11 `IconKind` vector primitives), unified bus-agnostic zero-copy display sink (`DisplaySink` + `present_sink`, `ByteWindowBus`/`ByteWindowSink`, `EgDisplaySink`), legacy `DrawTarget` uploader (`present_sync` / `present_sync_with`) & 1.x aliases (`SpiWindowBus` / `SpiWindowTarget`), RGB565 wire serializers (`wire.rs`: byte, word, and in-place), and compile-time-safe ping-pong DMA ownership protocol (`FreeBand` -> `ReadyBand` -> `InFlightBand`) with 32-byte cache alignment (`AlignedBand`), optional automatic `ByteOrder` conversion, `DmaCacheOps`, `TeGate`, guarded fault recovery, and strict `(frame, seq, slot)` completion validation.
- `crates/liuli`: Pre-allocated `.bss`-compatible `Storage` (`Storage::ZERO` / `Storage::new()`) + `Engine<A: App, F: FontProvider + TextMeasurer = FontSet<'f>>` orchestrating atomic scoped `ViewDraft` transactions (`handle_input`/`try_dispatch`, `send`/`try_message`, `tick`/`try_advance` + full rollback), active DMA frame locking (`ActiveDma`, `try_model_mut` / `try_with_model`), per-page focus & scroll save/restore hooks, unified `present` across `FontSet` and streaming fonts, `TouchTracker` + `MonotonicClock32` BSP helpers in `prelude`, and `wakeup`/`NextWakeup` power scheduling.
- `apps/liuli-settings`: Provides both the preserved 320x240 single-page `SettingsApp` and the v0.2 3-page `TerminalApp` (`Dashboard`, `Settings`, `Diagnostics`) using `Body16` + `Small12` fonts, `ProgressBar`, `Sparkline`, independent `PageMemory`, loop-free `DiagnosticsSnapshot`, confirmation modal, and non-focusable click-through `Toast`.
- `tools/liuli-fontpack`: Reproducible dual-slot (`Body16` + `Small12`) 4x-supersampled PBM + TSV -> LF4 v1 packer and verifier (`pack`, `verify`) with DirectWrite rasterization recipe.
- `host/liuli-sim`: Shared deterministic `SimSession` (`clock.rs`, `sim.rs`), host `MemoryScreen` (`DrawTarget`), independent fullscreen reference renderer, pure-Rust P6 PPM & RGB8 PNG codecs, strict replay CLI (`settings.events` + `terminal.events`, path-sanitized `shot` names), and read-only/time-traveling `127.0.0.1` HTTP `PreviewServer` (16-frame PNG ring + Damage/Band overlay canvas).
- `checks/firmware` & `checks/*.ps1`: Standalone bare-metal `thumbv7em-none-eabihf` verification firmware (`Reset` startup assembly, `AuditSink` exercising `poll_dma` & `SpiWindowTarget`, optional `startup-probe` `.data` copy check) plus offline scripts `audit-locks.ps1`, `audit-firmware.ps1`, and `audit-stack.ps1`.

## Transaction & Rendering Pipeline

1. **Scoped View Transaction**: `App::view(&model, &mut ViewBuilder)` builds the UI via `out.root(..., |ui| ...)` closures into `Storage.draft`. Any structural error (`DuplicateKey`, `UnmatchedEnd`, `UnclosedContainer`, `NestedModal`, `InvalidScrollFill`, `InvalidKind`, `InvalidRange`, capacity overflow) rolls back cleanly without mutating the active scene, focus, capture, animations, or accumulated damage.
2. **Iterative Reconciliation & Layout**: `reconcile_into` preserves slots and `NodeId` generations for matching `(Key, NodeKind)` pairs, frees deleted slots (monotonic `generation_hwm` without wraparound), uses fixed-bounds text fast paths to skip parent relayout (`measured_nodes == 0`), restores per-page scroll/focus state on page switch, and merges dirty rectangles into `DamageSet`.
3. **Strip Rendering**: `DamageSet` splits dirty regions into horizontal bands (`BandIter`). Every band clears to opaque `root_bg` and replays intersecting `PaintCmd` (`48 B`) primitives in z-order into a caller-provided `&mut [u16]` slice (`BandTarget`).
4. **Sync SPI & Locked DMA Output**: `present_sync_with` uploads bands synchronously (e.g., via chunked `SpiWindowTarget` + `flush` boundary). Asynchronous DMA frames lock `Engine` against mid-frame scene mutations (`ActiveDma`), enforce `AlignedBand` 32 B cache alignment and TE gating rules, and only clear damage once all bands return as confirmed-stopped `FreeBand`s matching `(frame, seq, slot)`.
5. **Monotonic Time, Repeats & Sleep**: Platform supplies `InstantMs(u64)`. `Engine::next_wakeup` computes `Now`, `At(t)` (earliest of animation tracks, 400/80 ms long-press repeat, and `App::next_deadline`), or `OnEvent` when idle or awaiting DMA completion.
