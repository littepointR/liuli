# `liuli` Architecture

`liuli` is a pure-Rust `#![no_std]`, zero-`alloc`, `#![forbid(unsafe_code)]` embedded GUI engine built on `embedded-graphics-core` (`0.4.1`) and `embedded-graphics` (`0.8.2`), paired with a pure-Rust host simulator (`liuli-sim`), CJK bitmap font packer (`liuli-fontpack`), offline i18n/Figma toolchains (`tools/liuli-i18n.py`, `tools/liuli-figma.py`), and Cortex-M4F ELF/stack audit firmware.

## Customization and pay-for-use requirements

- Applications and third-party widget packages must be able to use the same public APIs as built-in widgets to compose controls, replace visual and interaction defaults, and override them for a subtree or an instance. Keep engine invariants such as clipping, gesture cancellation and focus restoration consistent across customizations. A design language should be implementable in a consumer package.
- Applications must be able to omit optional capabilities and their assets at build time. Choose the smallest practical mechanism for each capability, such as a separate asset pack, a statically selected implementation or an optional Cargo dependency. A build that omits a capability must exclude its dedicated code and data and incur no extra per-node storage, scratch buffers, per-frame processing or timer wakeups for it. Runtime preferences may tune capabilities included in the build.
- Verify customization with a consumer that uses only the published API. When introducing an optional capability, compare the same minimal firmware before the change and with the capability omitted, using the same target and release settings. Check linked Flash sections and static RAM, plus stack, frame work or wakeups where the capability affects them. Enable the capability separately to measure its incremental cost. See the [firmware budget audits](memory-budget.md).

## Workspace Layout

- `crates/liuli-core`: Retained tree sized from the application scene (nodes, depth and text slots) with independent rendering and resource budgets, backed by generic bitset `NodeMask`, scoped closure builder (`ViewBuilder`, `Children<'parent, 'pool>`) with chainable `const fn` `NodeProps` builders, `RetainedNode`, `PaintCmd` (`GradientRect`, `Bitmap`, shapes, text, vector ops), flexbox/justify/grid/horizontal-scroll layout (`Justify`, `Children::grid`, `Children::scroll_x`), key-based reconciliation, damage tracking (`DamageSet`), unified input router, tab-aware & 2D directional focus/modal/page-restore navigation (`NavDir`), Q8 inertial `ScrollPhysics` (friction, overscroll bounce, snap), `Easing` animations, `RepeatState` timers (`400 ms` delay, `80 ms` repeat), `Rotation` transforms, `L565` v1/v2 flags (`L565_FLAG_CHROMA_KEY`, `L565_FLAG_ALPHA4`, `L565_FLAG_RLE`), and zero-alloc i18n (`LocaleTable`, `TextKey`, `LocaleId`, `format_template`, `plural_en`, `plural_cjk`).
- `crates/liuli-text`: Dual-slot `FontSet` (`Body16` + `Small12`) LF4 v1 binary bitmap font parser, glyph iterator/line wrapper (`TextMeasurer` with CRLF, negative bearing, ellipsis, and `Start`/`Center`/`End` alignment), streaming flash/SD font abstraction (`ReadAt`, `BlockCache`, `StoredFont`, `StreamingFont`, `HybridFontSet`), and RGB565 4-bit coverage (`a = 0..15`) channel blender.
- `crates/liuli-render`: Strip buffer (`BandTarget`), scene rasterizer (`render_band`, `render_band_with_accel`, `DrawAccel` / `SoftAccel`), `StoredBitmap` streaming L565 v1/v2 (A4/RLE/chroma-key) decoder, `GradientRect` strip renderer, unified bus-agnostic zero-copy display sink (`DisplaySink`, `present_sink`, `ByteWindowBus`/`ByteWindowSink`, `EgDisplaySink`, `RotatedDisplaySink`), legacy `present_sync` & `SpiWindowBus`/`SpiWindowTarget` aliases, wire serializers (`wire.rs`), ping-pong DMA ownership protocol (`FreeBand` -> `ReadyBand` -> `InFlightBand`, `AlignedBand`, `DmaCacheOps`, `TeGate`), and turnkey MIPI-DCS / touch decoders (`DisplayCmdBus`, `PanelConfig`, `St7789`, `Ili9341`, `Gc9a01`, `Rm67162`, `Gt911Decoder`, `Ft3168Decoder`, `Cst816Decoder`, `Xpt2046Calibrator`).
- `crates/liuli`: Pre-allocated `.bss`-compatible `Storage` (`Storage::ZERO` / `Storage::new()`) + `Engine<A: App, F: FontProvider + TextMeasurer = FontSet<'f>>` orchestrating atomic scoped `ViewDraft` transactions (`tick`/`try_advance`, `handle_input`/`try_dispatch`, `send`/`try_message`, full rollback), active DMA frame locking (`ActiveDma`, `try_model_mut` / `try_with_model`), per-page focus & scroll save/restore, unified `present`, `TouchTracker` + `MonotonicClock32` BSP helpers in `prelude`, and `wakeup`/`NextWakeup` power scheduling.
- `crates/liuli-widgets`: Theme tokens (`ColorScheme`, `Density`, `Shape`, `Typography`, `ElevationScale`, `GlassStyle`, `InteractionStyle`, `Motion`, `EffectsConfig`), `ThemedUi` + `SurfaceSpec` (`Material`, `Elevation`, `Compositor`, `ButtonVariant`), `controls` (`arc_knob`, `badge_button`, `paint_ticked_slider`), `inputs` (`checkbox`, `radio`, `dropdown`, `roller`, `multi_line_editor`), `data` (`data_table`, `gauge`, `spinner`, `rich_text`, `paint_bar_chart`, `paint_multi_line_chart`), `ime` (`soft_keyboard`, `text_box`, `FixedTextEditor`, `StaticPinyinDict`), `Navigator` / `RouteReturn`, and `PageTransition` (`TransitionKind`).
- `apps/liuli-settings`: 320x240 single-page `SettingsApp` and v0.2 3-page `TerminalApp` (`Dashboard`, `Settings`, `Diagnostics`) sharing one reusable static memory pool (`Storage`).
- `tools/liuli-fontpack` & `tools/`: Dual-slot LF4 packer (`liuli-fontpack`), L565 v1/v2 asset packer (`liuli-image --v2 --rle --chroma-key`), static i18n catalog compiler (`tools/liuli-i18n.py`), and offline Figma compiler / W3C token generator / linter / RGB565 diff (`tools/liuli-figma.py`).
- `host/liuli-sim`: Shared deterministic `SimSession` & `AppSession`, host `MemoryScreen`, fullscreen reference renderer, P6 PPM & RGB8 PNG codecs, strict replay CLI, and `PreviewServer` HTTP preview (16-frame PNG ring, Damage/Band overlay canvas, `FrameProfile` 64-frame telemetry ring at `GET /api/profile`, `FileWatcher` + `PreviewServer::watch_path` at `GET /api/watch`, and interactive performance HUD in `preview.html`).
- `checks/firmware` & `checks/*.ps1`: Bare-metal `thumbv7em-none-eabihf` verification firmware (`AuditSink`), plus offline `audit-locks.ps1`, `audit-firmware.ps1`, and `audit-stack.ps1`.

## Transaction & Rendering Pipeline

1. **Scoped View Transaction**: `App::view(&model)` returns a scene whose declaration the engine builds into `Storage.draft`. Structural or capacity errors roll back atomically without mutating the live scene, focus, capture, animations, or accumulated damage.
2. **Iterative Reconciliation & Layout**: `reconcile_into` preserves slots and `NodeId` generations for matching `(Key, NodeKind)` pairs, frees unused slots via monotonic generation counters, executes fixed-size `column`/`row`/`wrap`/`stack`/`grid`/`scroll`/`scroll_x` passes, updates `DamageSet`, and restores per-page scroll/focus state.
3. **Strip Rendering & Hardware Accel**: `DamageSet` splits dirty regions into horizontal bands (`BandIter`). Each band clears to opaque `root_bg` and replays intersecting `PaintCmd`s via `DrawAccel` (`SoftAccel` fallback or MCU 2D DMA/Chrom-ART hook) into a caller-provided `&mut [u16]` slice (`BandTarget`).
4. **Bus-Agnostic Output & Locked DMA**: `present_sink` / `present` delivers `&[u16]` strip slices directly to `DisplaySink` (SPI, QSPI, 8080 parallel, LTDC/SDRAM, or `RotatedDisplaySink`), while `poll_dma` drives non-blocking double-buffered `DmaSink` pipelines with strict `ActiveDma` mutation locks and `AlignedBand` cache safety.
5. **Monotonic Time, Physics & Power**: Platform provides `InstantMs(u64)` (or `MonotonicClock32`). `Engine::wakeup` / `next_wakeup` computes `Now`, `At(t)` (earliest of `Tween`, `PageTransition`, `ScrollPhysics`, `RepeatState`, and `App::next_deadline`), or `OnEvent`.
